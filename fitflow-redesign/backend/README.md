Node.js/Express services go here.

This folder will contain the FitFlow backend API, built with Node.js and Express, as recommended in Lab 5, Activity 2.

Planned structure:
- src/routes/        — User & Profile, Workout Planning, Nutrition Logging, Social/Community, Notifications
- src/middleware/    — auth verification, rate limiting
- src/db/            — PostgreSQL models/queries
- src/firebase/      — Firestore integration for real-time social features

Setup (once code is added):
    npm install
    npm run dev
